# ✨ CSS Glassmorphism Generator

A simple, interactive web tool built with HTML, Tailwind CSS, and Vanilla JavaScript that allows developers to design and generate custom frosted glass (glassmorphism) CSS styles instantly.

## Features
* Real-time adjustment sliders for blur intensity, opacity, and border-radius.
* Live visual preview box with colorful ambient background elements.
* One-click "Copy CSS" functionality with clipboard support.

## Live Demo
You can view and test this project live via GitHub Pages [here](https://deepika-rattewal.github.io/Glassmorphism-generator/).

## How to Run Locally
1. Clone this repository.
2. Open `generator.html` in any web browser.
